This folder contains 3 pdf supplementary plots relating to the paper:

	1) FigureS1.pdf: compares relative risk estimates for the 
	Thessaloniki data set, from a quasiPoisson and a Negative
	Binomial model.
	
	2) FigureS2.pdf: posterior predictive QQ plot for model checking
	of the Thessaloniki data.
	
	3) FigureS3.pdf: ACF plot of the observed Thessaloniki counts
	in addition to corresponding posterior predictive ACF estimates
	from a Negative Binomial GAM with and without temporal structures.
	
	4) FigureS4.pdf: Relative risk surface comparing Nicosia
	to Famagusta using the hierarchical model for Cyprus.
